# Concert Hall Types: an LLM Wiki

**Topic:** how the shape of a concert hall (shoebox, vineyard, fan-shaped, horseshoe) changes how music sounds, for readers new to the subject.

**Rules for every page**
1. Every claim ends with one or more source IDs like [S3]; the IDs are listed in [sources](sources.md).
2. If sources disagree, say so and log it in [conflicts](conflicts.md) instead of choosing silently.
3. Do not state anything that is not in a Wiki page. A slide deck built from this Wiki must cite pages and source IDs.
