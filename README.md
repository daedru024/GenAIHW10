# GenAIHW10
主題：用 LLM Wiki 做一份教學 HTML 簡報

### 作業說明：
這次作業請先建立一個自己主題的 LLM Wiki，再利用這個 Wiki 作為知識庫，製作一份可以實際瀏覽的 教學型 HTML 簡報。

例如：

建立「AI Agents」主題的 LLM Wiki

再利用 Wiki 中的內容，製作「AI Agents 是什麼？」的教學 HTML 簡報

這次的重點除了最後的簡報成果，也要特別說明：

你的 loop 或 graph 是怎麼設計的？資訊是如何被取得、整理、檢查，再產生成簡報內容的？

### 步驟一：建立自己的 LLM Wiki

主題可以自行選擇

使用「先討論、後生成」的方式建立 Wiki

至少 ingest 5 篇資料

### 步驟二：利用 LLM Wiki 製作教學 HTML 簡報

請讓 AI 使用你的 Wiki 作為知識來源，製作一份教學型 HTML 簡報。

簡報內容需能讓一個原本不熟悉該主題的人理解基本概念。

### 步驟三：說明你的 loop / graph 設計

請簡單說明你的流程，例如：
```text
取得資料 → 查詢 Wiki → 整理重點 → 檢查內容 → 產生簡報
```
並說明：
- 哪些步驟會重複執行？
- 哪些地方需要檢查或重新生成？
- 為什麼這樣設計？

### 步驟四：進行反思

完成一次實際執行後，簡單回答：
- 哪一個節點最常出錯？
- 你發現問題後，把檢查往前移到了哪一個步驟？
- 你有沒有因此修改 workflow / graph？為什麼？
